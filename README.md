# 股基罗盘 V1.3.32

面向个人和少量朋友使用的股票、ETF 与场外基金研究工作台。当前版本已从界面初稿升级为可运行的数据底座；仍坚持数据缺失留空、不生成演示行情、不构成投资建议。

## 已实现

- 强制账号登录：未登录只显示登录/注册页；持仓、交易流水、自选、行情同步和 AI 分析接口均拒绝未登录请求
- 账号与跨设备同步：邮箱/密码注册登录、30 天 HttpOnly 会话 Cookie；登录时将当前匿名设备的历史数据合并到账号空间，保留原设备副本
- 交易流水账本：新增买入、卖出、分红、费用、期初记录，按设备隔离保存；以 FIFO 成本批次回放剩余成本、已实现盈亏、分红、费用和批次数；保留旧版手填持仓快照，便于渐进迁移
- 分类型录入：股票/ETF 填成本与数量；场外基金填持有金额与收益金额
- 股票持仓收益表：按股票、今盈亏、总盈亏、总收益率、现价、成本、数量、市值/仓位、行情排列；缺失行情不补零
- 资产总览：首页汇总全部持仓，股票页和基金页分别汇总各自总资产、今日盈亏、累计盈亏和累计收益率
- 基金研究：天天基金与新浪基金双源核对产品/经理档案，按天天基金最新定期报告前十大股票计算基金重仓重叠，并按单只基金公开单位净值计算历史相似走势；单源部分明确标注
- 证券搜索：东方财富与腾讯证券搜索并行匹配 A 股、基金与美股，结果披露单源/多源状态；A 股和美股点击结果都可加入当前设备的自选库，刷新和重启后仍保留，并可逐项删除（各最多 30 只）
- 股票自选：A 股股票支持代码/名称搜索、永久保存、行情独立同步与逐项删除；随账号跨设备同步，不计入持仓或 AI 输入
- A 股与 ETF：东方财富与腾讯行情并行请求，价格偏差不超过 0.5% 时标记多源验证，超限标记来源冲突并保留主源数值；交易时段每 30 秒、其他时段每 5 分钟自动同步
- A 股行情工作台：四大指数真实日内位置、全部股票/行业板块/市场宽度切换；股票三榜由新浪财经主供、东方财富自动备用，各显示沪深京实时前 20，并统一展示名称/代码、最新价、涨跌额和涨跌幅；市场宽度优先采用 500 只成交活跃股票的独立样本，失败时退回三榜去重样本，页面始终披露实际样本量与口径；行业热力图取涨幅前 24 与跌幅前 24，共 48 个动态样本
- A 股行情搜索：嵌入市场中心；输入代码或名称，或点击排行股票，直接查看当日价格、区间、成交与数据时间，不保存持仓
- 场外基金：盘中估值，估值不可用时回退到最新已确认净值
- 资讯：聚合东方财富、新浪财经、证监会与中国政府网，支持快讯/政策/持仓筛选；重复事件合并并保留每个来源原文，天聚财经可通过服务端密钥选配
- 历史相似：股票并行读取东方财富与腾讯前复权日线并核对最新共同收盘，基金在最多 780 个开放日净值中匹配最近 15 日形态；披露来源状态、截止日、样本数、后续 5/20 日统计和最差回撤；股票页使用真实历史点绘制日/周/月 SVG 图表
- DeepSeek 白话研判：官方 Chat Completions 接口、服务端密钥、匿名化摘要、逐次确认弹窗；完整汇入逐只持仓行情、估值/最新公开财报、基金公开档案、历史与风险，以及四大指数、500 只动态市场宽度样本、48 个行业强弱样本、多源快讯/政策和持仓公告；先预测明天/下一交易日偏涨、震荡或偏跌，给出三种主观概率、最需关注的具体持仓、开盘观察点和直接参考动作；随后逐只持仓显示“标的名称 + 动作 + 原因 + 什么时候做”，缺失类别会主动降低把握度
- 美股：三大指数、自选行情、热门股成交榜、涨幅榜和跌幅榜均显示最新价、涨跌额和涨跌幅；交易时段每 30 秒、其他时段每 5 分钟，双公开行情源兜底
- 刷新保护：页面隐藏时暂停行情请求、返回时立即同步；手动刷新间隔 30 秒；服务端上游行情缓存 15 秒并合并并发请求
- 来源健康状态：行情、搜索、历史、估值与基金档案统一披露来源数及“多源验证/单源/来源冲突”；行情快照还返回覆盖范围、时间戳和失败/降级状态，行业与排行沿用最近快照时会明确标注；`/api/health` 显示账号库、行情适配层、资讯聚合和 DeepSeek 配置状态
- AI 证据包：2.0 版按持仓行情、指数、宽度、行业、资讯、公告、股票基本面、基金档案、逐只历史与风险十类列出实际/目标覆盖、来源、时间和缺失项；本地完整包还保留真实持仓名称、FIFO 成本批次和定期报告持仓，敏感数字与流水明细不发送给 DeepSeek
- 基本面 / 估值：个股页并行读取东方财富与腾讯的 PE(TTM)、PB、PS(TTM)、总市值，交叉核验并披露超过 10% 的字段冲突；同时读取东方财富最新公开财报的 ROE、营收增速和利润增速，缺失项明确留空；基金页支持名称/代码筛选与持有金额、收益排序
- 量化风险：基于最多 520 个复权交易日计算年化波动率、最大回撤、VaR95、下行偏差、胜率、最长连跌和风险等级
- 交互与视觉：两字导航、自动明暗主题、桌面与移动端响应式布局

## 数据与隐私边界

- 行情、基金和公告源只接收证券代码，不接收成本、数量或设备标识
- 自动搜索源只接收当次代码或名称关键词，不接收任何持仓数字
- DeepSeek 只在用户逐次确认后接收匿名编号、比例、涨跌/收益百分比、匿名化估值/财报与基金档案摘要、行业强弱、逐只风险/历史统计，以及公开指数、市场宽度、脱敏公告和多源资讯
- DeepSeek 不接收持仓证券代码、证券名称、成本、数量、持有/收益金额、交易流水明细、设备标识或 Cookie
- 美股自选只用于页面行情观察，不会并入持仓或发送给 DeepSeek
- 没有可用真实行情时暂停 AI 分析

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm ci
copy .env.example .env.local
npm run dev
```

新增 D1 交易流水表对应迁移 `drizzle/0003_high_enchantress.sql`，账号表与会话表对应迁移 `drizzle/0004_silent_account.sql`，股票自选表对应迁移 `drizzle/0005_stock_watchlist.sql`。部署前请先执行迁移，或让服务端的 `ensurePortfolioSchema()` 完成兼容性建表；匿名数据不会被覆盖。

打开 `http://localhost:3000/`。如需启用 AI 分析，可在服务端环境中直接配置 `DEEPSEEK_API_KEY`。如果服务器直连 DeepSeek 受阻，可改用自有 Cloudflare Worker，并配置完整的 `DEEPSEEK_RELAY_URL` 与独立的 `DEEPSEEK_RELAY_TOKEN`；DeepSeek Key 应只保存在 Worker 加密 Secret 中。不要把任何真实密钥或中转口令提交到 Git。
