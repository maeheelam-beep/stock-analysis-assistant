## 1. 使用前准备

- Node.js `22.13.0` 或更高版本
- npm（随 Node.js 安装）
- 可访问公开行情与资讯来源的网络
- 如需 AI 研判：DeepSeek API Key；本地网络受限时也可使用已有的 HTTPS 中转地址

> [!IMPORTANT]
> GitHub 仓库不包含任何真实 API Key、密码、中转口令、日志或本机临时文件。

## 2. 下载与启动

```bash
git clone https://github.com/maeheelam-beep/stock-analysis-assistant.git
cd stock-analysis-assistant
npm ci
```

复制环境变量模板：

Windows PowerShell：

```powershell
Copy-Item .env.example .env.local
```

macOS 或 Linux：

```bash
cp .env.example .env.local
```

启动本地开发服务：

```bash
npm run dev
```

浏览器打开 `http://localhost:3000/`。首次启动时，本地 Cloudflare D1 模拟环境会提供 `DB` 绑定；应用会按需创建账号、会话、持仓、自选和交易流水表。

## 3. 配置 DeepSeek

> [!TIP]
> 不配置 DeepSeek 时，持仓、行情、资讯、历史、风险和本地证据包仍可使用，只有“AI 分析”不可用。

### 方式一：使用 API Key

编辑 `.env.local`：

```dotenv
DEEPSEEK_API_KEY=你的真实APIKey
DEEPSEEK_MODEL=deepseek-v4-flash
```

API Key 只应存在于本地 `.env.local`。不要把它写进源码、Markdown、测试、日志或 Git 提交。

### 方式二：使用已有的 HTTPS 中转地址

如果本地网络无法稳定直连 DeepSeek，可配置已有的 HTTPS 中转地址：

```dotenv
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_RELAY_URL=https://你的中转域名/v1/chat/completions
DEEPSEEK_RELAY_TOKEN=独立的中转口令
```

中转地址必须是 HTTPS，且不能在 URL 中包含用户名或密码。配置中转地址后，应用优先使用中转；不要把任何真实中转口令提交到 Git。

修改环境变量后请重启开发服务。

## 4. 首次使用

1. 打开网站后选择“首次使用？注册”。
2. 输入邮箱和至少 8 位密码，创建私人账号。
3. 登录后进入“首页”，点击“添加持仓”。
4. 选择股票、ETF 或场外基金，再搜索代码或名称并点选正确结果。
5. 股票和 ETF 填写平均成本、持有数量；场外基金填写当前持有金额、持有收益。
6. 保存后等待行情、资讯和公告同步。

持仓、交易流水及自选会保存在账号空间。其他设备登录同一账号即可读取；退出登录后不能访问这些私有数据。

## 5. 主要功能

### 首页

- 汇总总资产、今日盈亏、累计盈亏和累计收益率。
- 展示每项持仓的现价、成本、数量、市值、仓位及行情状态。
- 支持按名称或代码筛选持仓。
- 场外基金没有可靠日内净值时，不计入今日盈亏，并显示待净值结算。

### 行情

- 查看四大 A 股指数、股票涨跌榜、成交额榜、市场宽度和行业热力图。
- 输入代码或名称可临时查询，不会自动加入持仓。
- 页面会标注来源、更新时间、单源、多源验证或来源冲突。

### 股票与基金

- 股票页提供持仓、自选、历史走势、估值、公开财报摘要和量化风险。
- 基金页提供产品/经理档案、最新公开定期报告前十大持仓、基金重仓重叠和历史相似统计。
- A 股股票自选和美股自选都不会计入持仓或 AI 分析。

### 资讯

- 聚合市场快讯、政策信息和持仓公告。
- 同一事件可合并展示，但保留各来源的原文入口。
- 第三方天聚财经源为可选项，可在 `.env.local` 配置 `TIANAPI_KEY`。

### 交易流水

- 可记录买入、卖出、分红、费用和期初记录。
- 系统按发生时间使用 FIFO（先进先出）回放成本批次。
- 删除流水会重新计算剩余成本、已实现盈亏、分红和费用。

## 6. 使用 AI 研判

1. 确保持仓已经取得至少一项真实行情。
2. 在首页点击“AI 分析”或“开始 AI 分析”。
3. 阅读匿名发送范围，每一次分析都需要单独确认。
4. 等待系统收集行情、指数、市场宽度、行业、资讯、公告、基本面、基金档案、历史与风险数据。
5. 查看下一交易日方向、三种主观概率、重点持仓、开盘观察点、逐只参考动作及数据缺失项。

会发送给 DeepSeek：匿名持仓编号、组合占比、四舍五入后的涨跌/收益百分比、匿名化研究摘要，以及公开市场数据。

不会发送给 DeepSeek：证券代码、证券名称、平均成本、持有数量、持有/收益金额、交易流水明细、设备标识或 Cookie。

“复制数据明细 JSON（完整）”生成的是本地完整证据包，其中可能含真实持仓信息。复制后请只保存在可信位置，不要粘贴到公开议题、聊天或 GitHub 提交中。

## 7. 刷新与数据状态

- A 股和美股在各自常规交易时段每 30 秒更新，其他时段每 5 分钟更新。
- 页面切到后台时暂停自动请求，返回后立即同步。
- 手动刷新至少间隔 30 秒。
- 数据缺失时页面留空或显示错误，不会填入演示数字。
- “来源冲突”表示多个来源差异超过项目阈值，系统保留主源数值并提示核验，不会静默平均。

## 10. 常见问题

### 页面提示“持仓数据库尚未配置”

确认运行环境提供了名为 `DB` 的 D1 绑定。本地请使用 `npm run dev` 启动项目，不要只打开生成的静态文件。

### 页面提示“AI 分析服务尚未配置”

检查 `.env.local` 中的 `DEEPSEEK_API_KEY`，或同时检查 `DEEPSEEK_RELAY_URL` 与 `DEEPSEEK_RELAY_TOKEN`。修改后重启服务。

### 有持仓但 AI 分析不能开始

AI 研判至少需要一项状态正常的真实行情。检查持仓代码和类型是否正确，并查看首页的数据源健康状态。

### 行情、基金或资讯暂时不可用

免费公开源可能限流、维护或调整接口。等待后重试，并根据页面显示的来源、时间与状态判断数据是否可用。

### Git 提示将提交环境文件或密钥

立即停止提交，确认 `.gitignore` 生效，并执行：

```bash
git status --short
git check-ignore -v .env.local
```

如果真实密钥曾进入提交历史，应立即在服务商控制台撤销并重新生成；仅从最新文件中删除并不能清除历史记录。
